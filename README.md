# martamjl.github.io
Website for PhD students in Economics.

## Website Structure

This website contains the following pages:

- **About Me** (`index.html`) - Profile photo and description
- **Research** (`research.html`) - Papers with titles, authors, abstracts, and links to PDFs/slides
- **CV** (`cv.html`) - Link to download CV in PDF format

## Customization Instructions

### 1. Update Personal Information

**About Me page (`index.html`):**
- Replace placeholder text with your actual information
- Add your profile photo to `assets/profile.jpg`

**Contact page (`contact.html`):**
- Update email address
- Update office address
- Update phone number
- Update links to Google Scholar, LinkedIn, Twitter, GitHub

### 2. Add Your Research

Edit `research.html` to add your papers:
- Update paper titles, authors, and abstracts
- Add PDF files to `assets/papers/`
- Add presentation slides to `assets/slides/`
- Update the file links in the HTML

### 3. Add Your CV

- Place your CV PDF file as `assets/cv.pdf`

### 4. Customize Colors and Styling

Edit `styles.css` to change colors, fonts, or layout. Key colors used:
- Primary: `#3498db` (blue)
- Dark: `#2c3e50` (navy)
- Background: `#f8f9fa` (light gray)

## Directory Structure

```
martamjl.github.io/
├── index.html          # About Me page (homepage)
├── research.html       # Research page
├── cv.html            # CV page
├── contact.html       # Contact page
├── styles.css         # CSS styling
├── assets/            # Assets directory
│   ├── profile.jpg    # Profile photo (add your own)
│   ├── cv.pdf        # CV PDF (add your own)
│   ├── papers/       # Research papers PDFs
│   └── slides/       # Presentation slides PDFs
└── README.md         # This file
```

## Publishing

This is a GitHub Pages website. After customizing:
1. Commit your changes
2. Push to the `main` branch
3. Enable GitHub Pages in repository settings
4. Your site will be available at `https://martamjl.github.io`
